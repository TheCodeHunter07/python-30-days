# Day 14 – More on Functions

## 📚 Topics Covered

- `*args` – Passing multiple positional arguments to a function.
- `**kwargs` – Passing multiple keyword arguments to a function.
- Lambda functions – Creating small anonymous functions.
- `map()` – Applying a function to every item in an iterable.
- `filter()` – Filtering elements based on a condition.
- Recursion – Understanding functions that call themselves.

## 📝 Assignments

### 1. average.py
Created a function that accepts any number of values using `*args` and calculates their average.

### 2. profile.py
Created a function using `**kwargs` to accept multiple profile details and display them in a formatted manner.

### 3. recursion.py
Implemented recursive functions for:

- Factorial of a number.
- Sum of all elements in a list.
- Reversing a string.

### 4. Stretch Assignment – Palindrome Filter
Used `filter()` and a lambda function to extract all palindrome words from a list.

A palindrome is a word that reads the same forward and backward, such as `madam`, `level`, and `radar`.

## 🎯 Learning Outcomes

- Learned how to work with variable-length positional and keyword arguments.
- Practiced writing lambda functions.
- Understood how `map()` and `filter()` process iterable data.
- Learned the fundamentals of recursion.
- Improved problem-solving skills by implementing recursive solutions.
