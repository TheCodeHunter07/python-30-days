# Student Records Manager

## Project Overview

Student Records Manager is a menu-driven Python application that allows users to manage student records.

Each student record contains a roll number, name, and marks in three subjects: Maths, Science, and English.

The application provides options to add, view, search, update, and delete student records, along with calculating the class topper and class average.

## Features

1. **Add Student**
   - Add a new student with a name, roll number, and subject marks.
   - Prevent duplicate roll numbers.

2. **View All Students**
   - Display all student records in a formatted table.

3. **Search Student**
   - Search students using their roll number.
   - Search students using their name.
   - Display a message when a student is not found.

4. **Update Student Marks**
   - Search for a student using their roll number.
   - Update marks in Maths, Science, or English.

5. **Delete Student**
   - Delete a student record using their roll number.

6. **Show Class Topper**
   - Calculate the total marks of each student.
   - Display the student with the highest total marks.

7. **Show Class Average**
   - Calculate the average marks of the class.

8. **Exit**
   - Exit the application.
