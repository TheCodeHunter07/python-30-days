# Day 9 – Dictionaries

## Stage 2: Data Structures

**Goal:** Learn how to store, access, update, and manage data using Python dictionaries.

## Topics Covered

- Key-value pairs
- Adding, updating, and deleting dictionary entries
- Dictionary methods:
  - `get()`
  - `keys()`
  - `values()`
  - `items()`
- Looping over dictionaries
- Working with nested dictionaries

## Assignments

| File | Description |
|---|---|
| `phonebook.py` | Build a menu-driven phonebook to add, search, update, and delete contacts. |
| `char_frequency.py` | Count how frequently each character appears in a string. |
| `student_dict.py` | Store 3 students using nested dictionaries and calculate each student's average marks. |
| `word_translator.py` | Create a small English-to-Hindi or English-to-Marathi dictionary that translates words individually. |

## Skills Practiced

- Working with key-value pairs
- Adding, accessing, updating, and deleting dictionary data
- Using built-in dictionary methods
- Iterating through dictionaries
- Organizing structured data using nested dictionaries
- Solving problems using dictionaries
