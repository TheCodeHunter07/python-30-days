# Day 13 – Functions

## 📚 Topics Covered

- Defining and calling functions
- Parameters and return values
- Default arguments and keyword arguments
- Local and global scope
- Docstrings
- Writing small, reusable functions
- Code refactoring

## 📝 Assignments

### 1. math_utils.py
Implemented mathematical utility functions:

- `is_prime(n)` – Checks whether a number is prime.
- `factorial(n)` – Calculates the factorial of a number.
- `fibonacci(n)` – Generates Fibonacci numbers.
- `gcd(a, b)` – Finds the Greatest Common Divisor of two numbers.

Each function includes a docstring explaining its purpose.

### 2. temperature.py
Created functions to convert temperatures between:

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- Fahrenheit to Kelvin
- Kelvin to Fahrenheit

### 3. number_guessing_game.py
Refactored the Day 5 number-guessing game using functions to make the code more organized, reusable, and readable.

### 4. password_strength.py (Stretch Assignment)
Created a password strength checker that classifies passwords as:

- Weak
- Medium
- Strong

It also provides explanations based on password characteristics.

## 🎯 Learning Outcome

Learned how to organize Python programs using functions, work with parameters and return values, understand variable scope, write docstrings, and improve code readability through refactoring.
