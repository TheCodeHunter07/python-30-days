# Day 7 – Lists

## Stage 2: Data Structures

**Goal:** Learn how to store, organize, and manipulate collections of data using Python lists.

## Topics Covered

- Creating lists
- List indexing and slicing
- List methods:
  - `append()`
  - `insert()`
  - `remove()`
  - `pop()`
  - `sort()`
  - `reverse()`
- Looping over lists
- Built-in functions: `len()`, `min()`, `max()`, `sum()`
- Membership operator: `in`

## Assignments

| File | Description |
|---|---|
| `marks_stats.py` | Calculate total, average, highest, and lowest marks for 5 subjects. |
| `shopping_list.py` | Build a menu-driven shopping list to add, remove, and view items until the user types `quit`. |
| `remove_duplicates.py` | Remove duplicate elements while maintaining the original order. |
| `second_largest.py` | Find the second-largest number in a list without using `sort()`. |

## Skills Practiced

- Working with lists
- Modifying and accessing list elements
- Iterating through collections
- Performing calculations on list data
- Removing duplicates while preserving order
- Finding values using loops and conditions
