# Day 15 – Modules and Packages

## 📚 Topics Covered

- Importing modules using `import`.
- Importing specific functions using `from ... import`.
- Using aliases while importing modules.
- Python standard library:
  - `math`
  - `random`
  - `datetime`
  - `os`
- Creating custom Python modules.
- Understanding `if __name__ == "__main__":`.
- Installing packages using `pip`.
- Creating and working with virtual environments using `venv`.

## 📝 Assignments

### 1. Custom Modules – assignment-01

- Moved the functions created on Day 13 into `utils.py`.
- Imported and reused those functions in `main.py`.
- Practiced creating and using custom Python modules.

### 2. Age Calculator – age_calculator.py

Created an age calculator using the `datetime` module.

Features:
- Calculates the user's exact age.
- Calculates the number of days remaining until the next birthday.

### 3. Password Generator – password_generator.py

Created a password generator using Python's `random` and `string` modules.

Features:
- Generates random passwords.
- Uses different character types.
- Helps generate strong and secure passwords.
