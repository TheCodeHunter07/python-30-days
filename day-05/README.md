# Day 5 — Python Loops

## Topics Covered
- `for` loops
- `while` loops
- `range()` function
- `break` statement
- `continue` statement
- Nested loops
- Loop counters and conditions

## Assignments Completed

### 1. tables.py
Accepts a number from the user and prints its multiplication table from 1 to 10 using a `for` loop.

### 2. sum_digits.py
Calculates the sum of a number's digits using a `while` loop, modulo (`%`), and integer division (`//`).

### 3. number_guess.py
Implements a number guessing game using Python's `random` module, conditional statements, loops, and an attempt counter.

### 4. patterns.py
Uses nested loops to print three patterns:
- Pyramid
- Inverted pyramid
- Number triangle

## Key Learnings
- Using `for` loops with `range()` to repeat operations.
- Using `while` loops when repetition depends on a condition.
- Extracting digits using modulo and integer division.
- Controlling loop execution with conditions and `break`.
- Tracking attempts using counters.
- Using nested loops to create patterns.
