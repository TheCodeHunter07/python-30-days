# Day 11 – Working with Nested Data

## Stage 2: Data Structures

**Goal:** Learn how to organize, search, filter, and sort structured data using lists of dictionaries.

## Topics Covered

- Lists of dictionaries
- Understanding how real-world and API data is structured
- Searching lists of dictionaries
- Filtering data based on conditions
- Sorting lists of dictionaries
- Sorting by dictionary keys using `lambda`
- Printing structured data in a neat table

## Assignments

| File | Description |
|---|---|
| `products.py` | Create a list of 8 product dictionaries containing name, price, category, and stock. Display products as a table, filter by category, sort by price, list out-of-stock products, and calculate total inventory value. |
| `stretch.py` | Group products by category into a dictionary of lists. |

## Skills Practiced

- Working with nested data structures
- Accessing dictionary values inside lists
- Searching and filtering structured data
- Sorting data using `sorted()` and `lambda`
- Displaying structured information in table format
- Grouping related data using dictionaries
