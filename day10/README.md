# Day 10 – Comprehensions and Useful Built-ins

## Stage 2: Data Structures

**Goal:** Learn to write concise and efficient Python code using comprehensions and useful built-in functions.

## Topics Covered

### Comprehensions
- List comprehensions
- List comprehensions with conditions
- Dictionary comprehensions
- Set comprehensions

### Useful Built-in Functions
- `enumerate()`
- `zip()`
- `sorted()` with `key=`

## Assignments

| File | Description |
|---|---|
| Loop Refactoring | Rewrite three earlier loop-based solutions using comprehensions. |
| `even_squares.py` | Generate squares of even numbers from 1 to 50 using a single comprehension. |
| `rank_students.py` | Use `zip()` to pair student names with marks and sort them from highest to lowest marks. |
| `word_lengths.py` | Build a `{word: length}` dictionary for a sentence using a comprehension. |

## Skills Practiced

- Writing list comprehensions with conditions
- Creating dictionaries and sets using comprehensions
- Using `enumerate()` to access indexes and values
- Using `zip()` to combine multiple collections
- Sorting data using `sorted()` and custom keys
- Writing concise and readable Python code
