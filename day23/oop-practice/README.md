# Day 23 – OOP in Practice

## Project: Mini Online Shop

### Overview
This project is a simple online shopping system built using Python and Object-Oriented Programming (OOP) concepts.

It allows customers to add products to their cart, remove products, calculate the total amount, and complete checkout while checking product availability.

## Features

- Create and manage products.
- Add products to a shopping cart.
- Remove products from the cart.
- Calculate the cart total.
- Check product availability.
- Process checkout and update product stock.
- Prevent purchases when stock is insufficient.
- Save product data into a JSON file.
- Load JSON data and convert it back into Product objects.
