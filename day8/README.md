# Day 8 – Tuples and Sets

## Stage 2: Data Structures

**Goal:** Understand tuples and sets and learn when to use different Python collection types.

## Topics Covered

### Tuples
- Tuple creation
- Immutability
- Packing and unpacking

### Sets
- Uniqueness of elements
- Adding elements using `add()`
- Removing elements using `remove()`

### Set Operations
- Union
- Intersection
- Difference

### Collection Selection
- When to choose a list
- When to choose a tuple
- When to choose a set

## Assignments

| File | Description |
|---|---|
| `coordinates.py` | Store 5 points as tuples and find the point closest to `(0, 0)`. |
| `common_friends.py` | Use sets to find common friends, all friends, and friends unique to each person. |
| `unique_words.py` | Extract unique words from a paragraph and print them in alphabetical order. |
| `vowel_checker.py` | Find which vowels appear and do not appear in a sentence. |

## Skills Practiced

- Working with immutable collections
- Understanding tuple packing and unpacking
- Removing duplicate values using sets
- Performing set operations
- Comparing collections
- Choosing appropriate data structures for different problems
