# Day 4 — Conditional Statements

## Topics Covered
- if, elif, and else
- Nested conditions
- Comparison operators
- Logical operators: and, or, not
- Truthy and falsy values

## Assignments Completed

### 1. grade.py
Accepts marks out of 100 and displays the corresponding grade.

### 2. leap_year.py
Checks whether a year is a leap year using divisibility rules.

### 3. login.py
Checks user-entered credentials against a hard-coded username and password.

### 4. electricity_bill.py
Calculates an electricity bill using different rates for different consumption slabs.

## Key Learnings
- Using conditional statements to make decisions.
- Comparing values using comparison operators.
- Combining conditions using logical operators.
- Using the modulo operator to check divisibility.
- Applying conditional logic to practical problems.
